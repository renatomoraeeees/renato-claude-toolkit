# Renato Claude Toolkit — regras globais opcionais

## Orquestração de desenvolvimento

Para tarefas de desenvolvimento de software, programação, debugging, arquitetura, frontend, backend, APIs, automação ou testes, siga o protocolo Master Developer quando a Skill `master-developer` estiver disponível.

Antes de executar trabalho de desenvolvimento, informe:

### Skills utilizadas
- `nome-da-skill` — motivo.

Se nenhuma Skill especializada for necessária:
### Skills utilizadas
- Nenhuma Skill especializada será utilizada nesta tarefa.

Não peça autorização para usar Skills. Informe e continue.

Se uma nova Skill se tornar necessária durante a execução, informe antes de utilizá-la.

Nunca invente nomes de Skills.
