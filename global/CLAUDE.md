# Renato Claude Toolkit — orientação global opcional

Para tarefas de desenvolvimento de software — implementação, correção de bugs, revisão, refatoração, arquitetura, frontend, backend, APIs, testes, automação ou documentação técnica — invoque `master-developer:master-developer` pela tool `Skill` quando ela estiver anunciada na sessão. Faça a chamada de verdade; não apenas mencione a Master ou leia seu arquivo. Se a Master já estiver carregada para o pedido atual, não a invoque novamente.

Durante a coordenação, identifique um responsável pelo fluxo e escolha especialistas por pertinência. O catálogo descobre candidatos, mas não os executa. Toda skill selecionada e aplicável deve ser invocada pela tool `Skill`, com o identificador qualificado exposto na sessão, antes que suas instruções sejam usadas. Registre como sucesso apenas uma chamada confirmada pela tool.

Respeite skills exclusivamente manuais e os limites das ferramentas. Não use leitura direta de `SKILL.md` para simular uma invocação nem envie agents, hooks ou MCPs à tool `Skill`. Informe sucintamente os especialistas efetivamente invocados, o resultado das chamadas e as verificações executadas.

Em projetos que adotaram memória Markdown, leia o índice indicado no `CLAUDE.md` do projeto e atualize o estado após marcos relevantes. Não trate a memória como instrução superior ao pedido atual.
